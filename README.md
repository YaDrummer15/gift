# 🍁 С Днём учителя, Елена Владимировна!

Поздравительная веб-страница для учителя русского языка и литературы — 
с тёплыми словами, рукописным письмом, пожеланиями и благодарностью от учеников.

## ✨ Что внутри

- **Рукописное письмо** с эффектом печатающегося текста
- **Цитата Л. Н. Толстого** о настоящем учителе
- **6 карточек-пожеланий** с анимацией при наведении
- **Блок благодарности за подготовку к ЕГЭ**
- **Модальное окно** с личным поздравлением
- **Атмосферные эффекты**: падающие осенние листья и золотые блёстки
- **Полная адаптивность** — красиво выглядит и на телефоне, и на компьютере
- **Доступность**: поддержка `prefers-reduced-motion` для пользователей с чувствительностью к анимации

## 📁 Структура проекта

```
.
├── index.html      # разметка страницы
├── style.css       # все стили и анимации
├── script.js       # интерактив (листья, блёстки, письмо, модалка)
└── README.md       # этот файл
```

## 🚀 Как запустить локально

Просто откройте `index.html` в браузере — никаких сборщиков и зависимостей не требуется.

Либо запустите локальный сервер (по желанию):

```bash
# Python 3
python -m http.server 8000

# или Node.js (если установлен npx)
npx serve
```

Затем откройте http://localhost:8000

## 🌐 Публикация на GitHub Pages

1. Загрузите файлы в репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save** — через минуту сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🛠 Технологии

- Чистый **HTML5**
- **CSS3** — кастомные свойства, градиенты, анимации, `clamp()`, гриды
- Ванильный **JavaScript** — IntersectionObserver, генерация DOM-элементов
- **Google Fonts**: Marck Script, Caveat, PT Serif, Cormorant Garamond, Raleway

## 📝 Заметки

- Фотография учителя загружается по внешней ссылке — при необходимости замените её в `index.html` на локальный файл в папке `images/`.
- Если хотите изменить текст поздравления — правьте блоки `<p class="handwritten" data-text="...">` в `index.html`.
